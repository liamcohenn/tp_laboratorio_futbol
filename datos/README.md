# Datos

**Pregunta de investigación:** ¿Qué peso y qué rentabilidad tienen las ventas de jugadores formados en inferiores frente a las de jugadores comprados?

**Dataset:** Transfermarkt (vía [dcaribou/transfermarkt-datasets](https://github.com/dcaribou/transfermarkt-datasets)). Ver [`raw/README.md`](raw/README.md) para el detalle de las tablas, cómo se descargaron y la propuesta de regla para clasificar jugadores de cantera vs. comprados.

Pendiente del grupo: acotar el análisis a un club o puñado de clubes/ligas concreto (todo Transfermarkt es demasiado amplio para los gráficos pedidos).
